# 努力向上的小牛 · 泰语打字练习（Thai Typing Practice）

一个纯前端（HTML/CSS/JS，无框架、无构建、可离线使用）的泰语打字练习网站。
双击打开 `index.html` 即可开始练习（联网时可用在线发音和释义翻译）。

## 功能

- **打开即练**：网站打开直接进入练习页，第一次按键开始计时
- **词卡显示**：上方泰语待输入词，下方英文、中文释义（可分别隐藏），下一词预览
- **发音**：输入前 / 输入完成后自动朗读（可选），另有 🔊 手动播放按钮
- **打字判定**：按 Kedmanee 标准键位映射，物理键盘直接输入（无需安装泰语键盘）；
  输错时泰语栏变红 + 响铃，可退格修改；**输满整词（无论对错）自动切换下一词**
- **虚拟键盘**：待输入字符按键反色高亮，实际按键闪烁，可鼠标点击输入（Shift 键可锁定上档）
- **统计**：平均速度（词/分）、错误字符数、正确率、已练时间、剩余时间、进度
- **计时**：1 / 2 / 3 / 5 / 10 分钟或不限；Esc 暂停 / 继续；切换窗口自动停止计时
- **词库**：
  - 内置《泰语 1000 常用词》（泰/英/中三语）
  - 内置《游客会话手册 327 条》
  - 自建词库：上传 .txt/.csv/.json 或直接粘贴，每库上限 1000 词，数量不限，可随时删除
  - **联网核对**：导入后可一键「补全缺失释义」（只有泰语也能自动补英/中释义）、
    「校对全部释义」（与机翻比对，差异较大时提示 ⚠ 并可一键采用机翻）
- **字体切换**：右上角按钮切换「传统带圈字体（默认，Leelawadee UI）」与
  「现代无圈字体（Noto Sans Thai，已内置本地字体文件，离线可用）」
- **成绩单**：时间到或手动结束后显示成绩，点「返回练习」直接开始新一轮

## 自建词库格式

每行一条，分隔符支持 Tab、逗号、分号，或只有泰语一列（导入后联网补全释义）：

```
สวัสดี,hello,你好
ขอบคุณ	thank you	谢谢
แมว
```

也支持 JSON：`[{"th":"สวัสดี","en":"hello","zh":"你好"}]`

## 发音说明

发音引擎可在 ⚙ 设置中选择：

| 引擎 | 说明 |
|---|---|
| 自动（默认） | 优先在线语音，失败自动退回系统语音 |
| 在线语音 | Google Translate TTS，音质较好，需联网（部分地区可能无法访问） |
| 系统语音 | Windows 需先安装泰语语音包 |

**推荐做法**：
1. Windows「设置 → 时间和语言 → 语音 → 添加语音 → 泰语(Thai)」，安装后系统语音即可离线使用（Niwat / Premwadee 音色）；
2. 或使用 Edge / Chrome 浏览器，其自带的在线泰语语音（Natural 类）效果更好。

## 键盘布局说明

固定采用泰国标准 **Kedmanee（เกษมณี）** 布局（TIS 820-2538 / Windows KBDTH0），
按物理键位映射：无论系统当前是什么输入法，直接按对应键位即输入泰文字符，
因此无需在系统中安装泰语键盘。虚拟键盘上每键均标注泰文字符与英文键位。

## 文件结构

```
thai-typing/
├── index.html          页面
├── css/style.css       样式
├── js/
│   ├── layouts.js      Kedmanee 键盘布局数据
│   ├── audio.js        音效 + TTS（系统/在线双引擎）
│   ├── translate.js    在线翻译（Google gtx → MyMemory 兜底）
│   ├── storage.js      设置与自建词库（localStorage）
│   ├── app.js          主程序
│   └── data/           内置词库数据（5×200 常用词 + 会话手册）
├── fonts/              无圈字体（Noto Sans Thai，本地 woff2）
└── tools/check_chars.py 词库字符可达性校验脚本
```

数据均保存在浏览器 localStorage，不上传任何服务器（翻译请求除外）。
